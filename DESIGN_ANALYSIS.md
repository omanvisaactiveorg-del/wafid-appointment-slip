## Design Elements

### Colors
- **Primary Background**: White (#FFFFFF)
- **Secondary Background**: Light gray (#f5f5f5)
- **Text**: Dark gray/black
- **Accent**: Red/Pink for highlights
- **Header/Footer Background**: Dark (appears to be dark blue or black)

### Typography
- **Headings**: Bold, larger font size
- **Body Text**: Regular weight, readable size
- **Labels**: Medium weight, slightly smaller

### Layout
- **Responsive**: Mobile-first design with hamburger menu
- **Container**: Centered content with padding
- **Tables**: Two-column layout for appointment details
- **Spacing**: Generous padding and margins
